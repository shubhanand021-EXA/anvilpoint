## Why ANVILPOINT

- **Evocative, not descriptive:** an anvil is where raw metal is *shaped* — what the
  workbench does to raw repositories. "Point" echoes developer-familiar checkpoint
  words (breakpoint, savepoint, restore point): readiness as a point in time.
- **Pronounceable, spellable, brandable:** three syllables, one obvious spelling,
  works as `anvilpoint` (package, CLI, domain-style) and ANVILPOINT (display).
- **Empty namespace:** zero GitHub repos, zero npm package, zero web hits at research time.

## Honest limitations (read before commercial use)

- This is a **namespace-collision check, not a legal trademark clearance**.
  It does not cover USPTO/EUIPO/WIPO registers, App Store/Play Store listings,
  company registers, domain portfolios, or non-English sources.
- Results reflect 2026-10-27; namespaces change. Re-run the checks before any
  commercial launch, and get professional counsel if money or liability is involved.
- If a conflict ever surfaces, the name is one variable: all brand strings live
  behind `ANVILPOINT`/`anvilpoint` tokens, so a future rename is mechanical.
